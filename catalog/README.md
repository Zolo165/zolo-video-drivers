# Каталог Zolo Video 4.0

catalog.json — каталог с подписью Ed25519. public-key.pem — ключ проверки; manifest-source.json — исходные данные для подписи.

Сейчас каталог содержит таблицы NVENC для конкретных версий Windows x64. Полных установщиков видеодрайверов в нём пока нет. Расширение лимита NVENC ещё требует проверки на физической Windows-машине.

Источник таблиц: https://github.com/keylase/nvidia-patch/tree/b68d0ed0c19d20a2c336879be18804b08bb63e89/win

Приложение использует встроенную копию, локальный кеш и офлайн-установку при недоступности GitHub. Пакеты сопоставляются с PCI ID и версией Windows, проверяются по SHA-256 и подписи производителя. Закрытый ключ и личные данные в репозиторий не входят.
